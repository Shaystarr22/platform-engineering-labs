# 05 - Terraform Labs

## Purpose
This directory contains Infrastructure as Code (IaC) labs using HashiCorp Terraform to declaratively provision, manage, and version cloud infrastructure.

## Learning Objectives
- Understand the Terraform workflow (`init`, `fmt`, `validate`, `plan`, `apply`, `destroy`).
- Use providers, resources, input variables, outputs, and local values effectively.
- Manage Terraform state safely and understand remote backends and state locking.
- Build reusable, maintainable Terraform modules.

## Labs
- `lab-01-first-ec2/` — Provisioning an EC2 instance and security group using Terraform.
- `lab-02-s3-static-site/` — Deploying and configuring an S3 static website with IaC.
