# 06 - Kubernetes Labs

## Purpose
This directory contains labs for deploying, scaling, and managing containerized workloads on Kubernetes clusters.

## Learning Objectives
- Understand Kubernetes cluster architecture and core API objects.
- Write declarative YAML manifests for Pods, ReplicaSets, Deployments, and Services.
- Configure application settings and secrets using `ConfigMap` and `Secret` resources.
- Perform rolling updates, health checks (liveness/readiness probes), and basic cluster troubleshooting with `kubectl`.

## Labs
- `lab-01-pods-and-services/` — Running Pods and exposing them with Kubernetes Services.
- `lab-02-deployments/` — Managing application lifecycle, scaling, and rolling updates with Deployments.
