# 03 - Docker Labs

## Purpose
This directory contains labs dedicated to building, running, optimizing, and orchestrating application containers using Docker and Docker Compose.

## Learning Objectives
- Understand container fundamentals, images, layers, and registries.
- Write clean, secure `Dockerfile`s and use multi-stage builds to minimize image size.
- Configure container networking, volumes, and environment variables.
- Define and run multi-container applications locally using `docker-compose.yml`.

## Labs
- `lab-01-first-container/` — Packaging and running a containerized application with a `Dockerfile`.
- `lab-02-docker-compose/` — Running a multi-container stack with Docker Compose.
