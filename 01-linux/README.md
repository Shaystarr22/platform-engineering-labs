# 01 - Linux Labs

## Purpose
This directory contains hands-on labs focused on Linux system administration, command-line proficiency, and shell scripting—the foundational operating system skills required for Platform Engineering and DevOps.

## Learning Objectives
- Navigate the Linux filesystem and manage files, directories, and permissions (`chmod`, `chown`).
- Understand processes, system services (`systemd`), and resource monitoring (`top`, `ps`, `df`, `free`).
- Inspect and troubleshoot basic networking (`ip`, `ss`, `curl`, `dig`, `ssh`).
- Write automated Bash scripts using variables, loops, conditionals, and error handling.

## Labs
- `lab-01-basic-commands/` — Filesystem navigation, permissions, and text processing.
- `lab-02-bash-scripting/` — Automating system tasks with Bash scripts.
