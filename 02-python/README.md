# 02 - Python Labs

## Purpose
This directory contains Python labs focused on infrastructure automation, CLI tooling, API interactions, and cloud resource management for Platform Engineering workflows.

## Learning Objectives
- Write clean, modular Python scripts for file handling, log parsing, and task automation.
- Work with common data formats used in infrastructure (`JSON`, `YAML`, environment variables).
- Interact with REST APIs and handle errors gracefully.
- Automate AWS cloud operations using the AWS SDK for Python (`boto3`).

## Labs
- `lab-01-file-automation/` — Automating file operations and parsing structured data.
- `lab-02-aws-boto3/` — Interacting with AWS services programmatically using `boto3`.
