# 04 - AWS Labs

## Purpose
This directory documents hands-on Amazon Web Services (AWS) labs, architecture designs, and AWS CLI workflows covering core cloud infrastructure services.

## Learning Objectives
- Configure least-privilege access using AWS Identity and Access Management (IAM).
- Provision and manage object storage with Amazon S3.
- Design and troubleshoot Virtual Private Cloud (VPC) networking (subnets, route tables, security groups).
- Deploy compute resources (EC2, Lambda) and understand core cloud security and cost best practices.

## Labs
- `lab-01-iam-and-s3/` — Managing IAM policies, users/roles, and S3 buckets.
- `lab-02-vpc-networking/` — Building and understanding custom VPCs, subnets, and security groups.
